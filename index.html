Configuration Google

1 — Identifiant OAuth Google

Créez un « ID client OAuth » de type Application Web dans Google Cloud Console, activez l'API Google Sheets, puis ajoutez l'adresse à laquelle vous hébergez ce fichier dans « Origines JavaScript autorisées ». Le mode file:// ne fonctionne pas avec la connexion Google — il faut un vrai lien http/https. Pour ce fichier, ajoutez exactement : https://mobafibre.github.io

2 — Vos 6 feuilles Google Sheets

Pour chaque registre, collez l'ID de la feuille (dans l'URL entre /d/ et /edit) et le nom de l'onglet exact.

3 — Enregistrer

Ces réglages restent actifs pendant votre session. Pour les rendre permanents, ouvrez le fichier HTML et modifiez l'objet CONFIG au tout début du script avec vos identifiants.
